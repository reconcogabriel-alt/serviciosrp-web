# **App Name**: Servicios RP

## Core Features:

- Hero Section Display: Render the prominent header section with company logo, dynamic slogan, main headline, introductory description, and two call-to-action buttons.
- Dynamic Content Management: Provide administrative controls for updating textual content across the landing page, including company statistics, service descriptions, 'About Us' profile, and corporate values, without needing to edit code directly.
- Services Portfolio Grid: Display an adaptive grid showcasing company services, each with an SVG icon, title, and a brief description, with automatic layout adjustments based on the number of items.
- Contact Information Display: Present company contact details, including multiple email addresses, phone numbers, and location, clearly in both the 'About Us' section and the footer.
- AI Copywriter Tool: Integrate a generative AI tool to suggest engaging marketing copy for headlines, slogans, service descriptions, and company values based on input keywords and company focus, helping to refine messaging.
- Formspree Contact Form Integration: Embed a contact form that routes submissions through Formspree, enabling easy lead capture directly to company email without requiring backend server development.
- Responsive Page Structure: Ensure all sections and content adapt seamlessly to various screen sizes, from mobile devices to desktop monitors, providing an optimal viewing experience for all users.

## Style Guidelines:

- Primary color: Deep Corporate Blue (#025196), embodying professionalism and reliability for branding elements and key interactive components. (Derived from HSL: 206, 97%, 30%).
- Background color: A subtle Cool Off-White (#ECF3F6), offering a clean and bright canvas that enhances readability and pairs harmoniously with the primary blue. (Derived from HSL: 206, 20%, 96%).
- Accent color: A vibrant Electric Indigo (#1A5BF1), providing a clear analogous contrast to the primary blue, used for highlighting interactive elements and calls to action. (Derived from HSL: 236, 80%, 50%).
- Secondary accent: A distinct Golden hue (#FDB338), prominently featured for high-visibility items like key metrics and CTA buttons, adding an element of prestige as per the corporate identity.
- Headline font: 'Playfair Display' (serif), for titles and main headings, conveying a sense of elegance, professionalism, and solid brand presence.
- Body font: 'Source Sans 3' (sans-serif), for paragraphs, button labels, and general text, ensuring clarity, modernity, and excellent legibility across all sections. Note: currently only Google Fonts are supported.
- Employ clean, vector-based SVG icons sourced from libraries like heroicons.com or iconify.design, ensuring scalability and crisp visual fidelity for services, statistics, and values.
- Structured single-page design with clear vertical separation between content sections, optimized for scroll-based navigation, presenting information logically and attractively.
- Adaptive grid layouts for showcasing services, statistics, and values, ensuring content remains organized and visually appealing on screens of all sizes.
- Subtle, non-intrusive scroll-triggered animations (e.g., gentle fades or slides) for sections and content elements, enhancing perceived fluidity and engagement without distracting the user.
